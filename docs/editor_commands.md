# 总编口令

在 Codex app 里优先说口令，不需要记脚本链条。

## 常用

```text
查状态，并给我下一步提示词。
给我下一步提示词。
按防漂移流程生成下一章 brief。
确认 brief，开章 v01_c001。
收章 v01_c001。
```

## 防漂移 brief

```text
按长篇防漂移流程生成下一章 brief：先清点人物状态、道具、技能、能力限制和未解决伏笔，再写本章目标、阻力、主动选择和章末问题；新增道具/技能只放“新增设定”等我确认。
```

## Gate 提醒

第 3、10、25、125 章完成后，必须优先进入对应 Gate。Gate 只检查证据，不会自动通过，最终由人类总编裁决。
